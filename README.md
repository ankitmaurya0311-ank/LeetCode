# LeetCode Solutions

A collection of my solutions to LeetCode problems, organized by problem and topic.

I use this repository to practice Data Structures & Algorithms, improve problem-solving skills, and maintain a record of my coding journey.

## 🎯 DSA Patterns I'm Practicing

I am solving problems using common DSA patterns and problem-solving techniques:

1. **Arrays & Hashing**
   - Frequency counting, HashMap/HashSet, duplicates, grouping

2. **Two Pointers**
   - Opposite pointers, same-direction pointers, sorted arrays

3. **Sliding Window**
   - Fixed-size and variable-size windows, subarrays, substrings

4. **Binary Search**
   - Search space reduction, lower/upper bound, answer-based binary search

5. **Prefix Sum & Difference Array**
   - Range queries, subarray sums, cumulative calculations

6. **Stack & Monotonic Stack**
   - Next greater/smaller element, parentheses, histogram problems

7. **Intervals**
   - Merge intervals, overlapping intervals, scheduling problems

8. **Linked List**
   - Fast & slow pointers, reversal, cycle detection, merging

9. **Trees & Binary Search Trees**
   - DFS, BFS, traversals, height, path problems, BST operations

10. **Heap / Priority Queue**
    - Top K elements, Kth largest/smallest, scheduling, merging

11. **Backtracking**
    - Subsets, permutations, combinations, N-Queens, constraint problems

12. **Graphs**
    - BFS, DFS, connected components, shortest path, cycle detection

13. **Greedy**
    - Local optimal choices, interval scheduling, optimization problems

14. **Dynamic Programming**
    - 1D/2D DP, memoization, tabulation, subsequences, knapsack patterns

15. **Bit Manipulation**
    - XOR, bit masks, set/unset bits, binary representation

## 🚀 Repository Goals

- Build strong problem-solving fundamentals
- Recognize common DSA patterns
- Write clean and readable Python solutions
- Analyze time and space complexity
- Maintain a structured record of solved problems
- Prepare for technical interviews and coding assessments
